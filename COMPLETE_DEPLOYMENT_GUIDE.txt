=================================================================
 TROUBLESHOOTING
=================================================================

Problem: API returns "data" instead of "shifts"
Solution:
1. Run deploy_backend.bat
2. Restart Flask server
3. Test API again

Problem: working_hours is null or missing
Solution:
1. Check database: SELECT * FROM spell_mst;
2. Update if needed: UPDATE spell_mst SET working_hours = 8.0;
3. Restart server

Problem: Hours don't auto-fill in app
Solution:
1. Check backend deployed: e:\sjm\attendancesystem\app.py
2. Check server restarted
3. Test API in browser
4. Rebuild APK if backend OK
5. Reinstall APK

Problem: Server won't start
Solution:
1. Check port 5051 not in use
2. Check MySQL running
3. Check Python version (3.7+)
4. Check database credentials
