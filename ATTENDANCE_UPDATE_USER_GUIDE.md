# Attendance Update - Quick User Guide

## How to Use Attendance Update Feature

### 📱 Accessing the Feature

1. Open MyHrms app on your mobile device
2. Login with your credentials
3. From the main dashboard, tap **Attendance** section
4. Select **🔄 Attendance Update**

---

## 🔍 Searching for Attendance Records

### Step-by-Step Instructions:

#### 1. Basic Search (All Records)
- The screen opens with default dates (last 7 days)
- Simply tap **🔍 SEARCH** button
- All records for the date range will be displayed

#### 2. Search by Employee Code
- Enter employee code in "Employee Code" field (e.g., `13177`)
- Tap **🔍 SEARCH**
- Shows all records for that employee

#### 3. Search by Employee Name
- Enter name in "Employee Name" field (e.g., `John`)
- Can enter partial name (searches anywhere in the name)
- Tap **🔍 SEARCH**

#### 4. Search by Date Range
- Tap "From Date" field → Select start date from calendar
- Tap "To Date" field → Select end date from calendar
- Tap **🔍 SEARCH**

#### 5. Search by Shift
- Tap "Shift" dropdown
- Select desired shift (e.g., "Morning Shift")
- Tap **🔍 SEARCH**

#### 6. Combined Search
- Fill in multiple fields for more specific search
- Example: Employee Code + Date Range + Shift
- Tap **🔍 SEARCH**

---

## 📋 Understanding the Results

### What You'll See:

Each attendance record displays:
- **Employee Code** (e.g., 13177)
- **Employee Name** (e.g., KRISHNA PRASAD)
- **📅 Date** (e.g., 2026-04-23)
- **⏰ Shift** (e.g., Morning Shift)
- **💼 Working Hours** (e.g., 8.0 hrs)

### Results Information:
- **Record Count**: Shown at top (e.g., "15 record(s) found")
- **Scroll**: Swipe up/down to see more records
- **Tap Record**: Shows record ID (edit coming soon)

## ✖ Clearing Filters

To start a new search:
1. Tap **✖ CLEAR FILTERS** button
2. All fields reset to defaults
3. Enter new search criteria
4. Tap **🔍 SEARCH** again

---

## 💡 Search Tips

### Best Practices:

✅ **DO:**
- Start with broader date ranges, then narrow down
- Use partial names for name searches
- Combine filters for precise results
- Check the record count before scrolling

❌ **DON'T:**
- Use very large date ranges (may be slow)
- Enter non-existent employee codes
- Forget to tap SEARCH after changing filters

## ⚠️ Troubleshooting

### "No records found" Message

**Possible Reasons:**
- Date range has no attendance records
- Employee code doesn't exist
- No records match the filter combination
- Employee not in your branch

**Solution:**
- Try broader date range
- Check employee code is correct
- Remove some filters
- Try different search criteria

### Slow Loading

**If search takes too long:**
- Reduce date range
- Be more specific with filters
- Check internet connection
- Close and reopen the screen

### Can't Edit Records

**Current Status:**
- List and search: ✅ Working
- Edit functionality: 🔄 Coming in next update
- For now: Tap record to see ID

## 📊 Understanding Data

### Attendance Types:
- **R** = Regular attendance
- **O** = Overtime attendance
- **C** = Cash attendance

### Status:
- **Manual** = Manually entered by admin
- **Face** = Marked using face recognition

### Hours:
- **Shift Hours** = Total scheduled hours
- **Working Hours** = Actual hours worked
- **Idle Hours** = Break/downtime
