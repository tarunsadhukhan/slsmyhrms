=================================================================
  THE WORKING_HOURS API
=================================================================

Endpoint: GET /shifts
Location in code: E:\sjm\MyHrms\app.py (Line 354-386)
Location in code should be: E:\sjm\Attendancesystem\app.py (Line 354-386)
Features:
✅ Returns working_hours for each spell
✅ COALESCE(working_hours, 8.0) - defaults to 8.0 if NULL
✅ Optional branch_id filtering
✅ Response key: 'shifts' (FIXED from 'data')

Query:
```sql
SELECT spell_id AS id, spell_name AS name,
       starting_time AS start_time, end_time,
       COALESCE(working_hours, 8.0) AS working_hours
FROM spell_mst
ORDER BY spell_name
```

Response Format:
```json
{
  "status": "success",
  "shifts": [
    {
      "id": 91,
      "name": "A1",
      "start_time": "11:00:00",
      "end_time": "06:00:00",
      "working_hours": 5.0
    }
  ],
  "total": 1
}
```
